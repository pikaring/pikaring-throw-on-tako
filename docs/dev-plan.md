# 開発の しくみ（分担と 受け渡しの 決まり）

「街と、その白い壁 〜The City and Its White Squid〜」を **3つの担当が 同時に 作る**ための 決まりです。
前作 cat-on-escape の `docs/story-mode.md` と 同じ やり方です。ここに 書いた 形（ファイル・データ・関数）を 守れば、
ほかの 担当を 待たずに 進められます。

公開 URL は `https://pikaring.github.io/white-squid/`（リポジトリ名 `white-squid`）。

## どんな ゲームか

- **たて画面の 見下ろし型**。ビリヤード／モンスターストライクの ように、画面の どこでも 指で 引っぱって はなすと、
  下の 発射口から **反対向き**に タコが とびだす。引く 長さが 強さ。
- 予測線は 台の ふちや ブロックで はねかえる 道すじを 見せる（長さは 投げる 人で ちがう）。
- タコは 台の ふちや ブロックで はねかえり、**ゆっくり 回りながら すべって**、止まると **場に のこる**。
- **場に のこった タコに あてると コンボ**。コンボの ついた タコが イカに あたると ダメージ アップ（コンボ 1ごとに ＋50%）。
- 白い 壁（四角い ブロック）に まもられた **イカを 攻撃**。イカの 体力（ハート、`hp`）を 0 に したら 勝ち。
  1面の はじめは 1回 あてれば 勝ち。面が すすむと イカの 体力も タコの かずも ふえる（1面 3びき → 8面 9ひき）。
- **イカを はじいて 四すみの 穴に おとしたら 一発 勝利**（★が 1つ おまけ。のこりの 体力×500点）。穴は `POCKET_R` 36・`POCKET_IN` 52（イカの 中心が この 距離に 入ったら 落ちる）。
- ブロック（`KINDS`）：白 `W`＝2回 あてると こわれる、かたい `H`＝ふつうには こわれない（二郎で けずれ、爆発なら 1回で こわれる。七郎の スミで 白に なる）、
  赤 `R`＝あたると 爆発して まわりの ブロックを こわし、ちかくの イカにも ダメージ。白い 玉 `O`＝あてると うごき、コンボに なる。
- 発射ゾーン（点線の 下）を タップすると、発射口が そこへ うごく（まっすぐ ふさがれた ときに かべで はねかえして ねらう）。
- はねかえりは 入った 角度と 同じ 角度（速さだけ へる）。
- アイテム：はじめは ナオと タコ一郎だけ。台の アイテム（`app/stages.js` の `'f@r,c'`・`'2#r,c'` など）で 投げる 人・タコが ふえる。
  **手に 入れた ものは クリアで 同じ 面の つぎの レベルへ もちこす**（保存の `carry`。なかまと、あまった タコ。面が かわると なし）。
- 得点：レベルごとに ダメージ（ハート 1つ 100）・穴（1,000＋のこりの ハート×500）・さいだい コンボ×200・のこった タコ一郎×300。
  面の さいごに あまった タコ二郎〜大王×500・使わずに のこった なかま×800 を 足して、面の 合計を ハイスコア（保存の `best`）と くらべる。数値は `main.js` の `PT`。
  `tools/sim_check.js` は もちこし なしで 確かめる（もちこしは 有利に しか ならないので、なしで 勝てれば よい）。
- タコも 玉も よく すべる（まさつ 90〜170。三郎が いちばん すべる）。
- 台の 形：イカは 発射口の 左か 右に よせ、そばに 赤い ブロック、真下に 壁。**1回 はねかえせば あたる** 道が かならず あり、ブロックの あいだの 通路は **2マス 以上**。
- 予測線が 赤い ブロックに とどくと、爆発の はんい（点線の 円）を 出し、イカに とどく ときは イカを 光らせる。
- 背景の 絵は ストーリーの 場面だけ。ゲームの 画面は 空色の 台。
- 物理演算は 自前（`app/game.js`）。依存ライブラリなし・通信なし。

## 全体の 流れ

```
タイトル ─┬─ はじめから ─→ prologue → stage1 → [1-1 1-2 1-3] → clear1 → stage2 → … → clear8 → ending → タイトル
          ├─ つづきから ─→ 保存した レベルから（面の はじめなら stageN を 先に）
          └─ えらんで あそぶ ─→ クリアした ところまでの レベルを 1つ えらぶ（会話なし）
```

- **1面＝3レベル（3つの 台）、全8面・24レベル**。レベル `n` の 面は `Math.ceil(n / 3)`。
- 面の 1つめを 始める まえに `stageN`、3つめを クリアしたら `clearN` の 場面を 再生する。

## ① `window.STAGES` の 形

```js
window.STAGES = [
  {
    no: 1,                 // 1〜24
    stage: 1,              // 面（1〜8）
    name: '1-1',
    hp: 1,                 // イカの 体力（1 あてる ごとに だいたい 1 へる）。0 に したら 勝ち
    rows: [                // 台の 図面（見下ろし）。よこ 9マスで 書く（イカの がわの はしに よせて よこ 13マスの 台に する）× たて 8マスまで（1マス 40）。いちばん 上の 行が 台の 上の はし
      '.........',         //   Q イカ（1ぴき）・W 白（2回で こわれる）・H かたい（二郎・爆発で こわれる）・R 赤（爆発）・O 白い 玉・. なにもない
      '.........',         //   四すみには 穴が ある ので、左上・右上の マスは あけて おく
      '.........',
      '....Q....',
    ],
    takos: { tako1: 3 },   // 投げられる タコと かず（面ごとに ふえる：1面 3 → 8面 8。その 面の 新しい タコは 2ひき、大王は 1ぴき）
    throwers: ['nao', 'fumi', 'maki'],   // 使える 人（2面から chika も）
    hint: 'ひっぱって はなすと タコが とぶよ。イカに 1回 あてれば 勝ち！',  // レベルの はじめに 出す ひとこと
  },
  // … 24こ
];
```

- `goal`（こわす わりあい）は もう 無い。勝ちは「イカの `hp` を 0 に する」か「イカを 穴に おとす」。
- 図面と タコの かずは `node tools/sim_check.js` で 確かめる。24レベル すべてで
  (a) **置いた ままで 動かない**（何も 投げずに まわしても イカも ブロックも うごかない）、
  (b) **毎回 いちばん よい 投げ（角度×強さ×人×タコ）で、入れた タコの かず 以内に 勝てる**、
  (c) **1回 以内の はねかえりで イカに あたる**（発射口の 位置と 角度を ぜんぶ ためす。赤の 爆発が とどくのも あたりに 数える）、
  (d) **1マスの せまい 通路が ない** こと（いまは 全部 OK）。
  `node tools/sim_check.js 5 12` の ように レベルを えらぶと、投げの 記録も 出る。

## ① `window.TakoGame` の 形（`app/game.js`）

```js
const g = TakoGame.create(canvas, {
  onStats({ hp, maxHp, ratio, won, pocket, combo, phase }) {},   // イカの 体力などが かわった とき
  onThrow(takoKey, throwerKey) {},                                // 投げた とき（② が タコの かずを へらす）
  onTurnEnd({ hp, maxHp, ratio, won, pocket, combo, phase }) {},  // 投げた あと ぜんぶ 止まった とき（② が 勝ち／つぎ／もういちどを 決める）
});
// hp・maxHp：イカの 体力、ratio：へらした わりあい（0〜1）、won：勝ったか、
// pocket：穴に おとして 勝ったか、combo：その レベルで いちばん 大きい コンボ
g.load(STAGES[n - 1], { boss: 'ika1' });   // 台を 組む（boss は イカの 絵の キー。'queen' は 大きく おもい）
g.setTako('tako1');
g.setThrower('nao');
g.start();          // 1回だけ（描画ループ）
g.resize();         // 画面の 大きさが かわった とき
g.pause(true);      // モーダルを 出して いる あいだ など
g.phase;            // 'aim' | 'move' | 'done'
g.bossDown();       // 勝った あと、イカを たおれた 絵に する
TakoGame.TAKOS / TakoGame.TAKO_ORDER / TakoGame.THROWERS / TakoGame.KINDS   // 名前・説明・色（トレイや ボタンの 表示に 使う）
```

- 台は ワールドの 点で よこ 520 × たて 400 の よこ長（上の 320 が 図面、発射ラインより 下が 発射口）。四すみに 穴（イカも タコも 玉も おちる）。
- なかまは アイテムで 1回だけ（`main.js` の `USES`）。使える あいだに また ひろっても ふえない。のこりは もちこし・面の さいごに 1人 800点。
- チカの 小さい タコは まさつ 0.4ばい（ぶつけられると 長く すべる）。
- canvas の 大きさは ② の CSS で 決める。`game.js` は `getBoundingClientRect()` に あわせて 縮めて 描く。
- 画像は `images/story/<キー>-normal.png`（`-down.png`）を 読めた ときだけ 使う。ない ときは 図形で 描く。
  ゲームの 画面に 背景の 絵は 使わない（空色の 台）。

## ② 画面と 流れ

- 前作 cat-on-escape の 見た目（ヘッダー・大きな ボタン・モーダル・ひらがなの 分かち書き）に そろえる。
- 画面：上に ヘッダー（面と レベル・イカの 体力〈♥〉の ゲージ・ひとこと）、まんなかに canvas、下に
  **タコの トレイ**（のこりの かず つき）と **投げる 人の ボタン**、「やりなおす」「タイトル」。
- 星（`main.js` の `starCount`）：勝った とき のこった タコが 2ひき 以上 ★3、1ぴき ★2、0 ★1。穴に おとしたら ★+1（最大 3）。
- タコが なくなっても イカが のこれば 「もういちど」。
- 保存キー `throwontako.story`：`{ level, stars: { 1: 3, … }, seenPrologue, carry: { 2: { throwers: ["fumi"], takos: { tako2: 1 } } }, scores: { 1: 2300 }, best: { 1: 8400 } }`。
- タイトルは `StoryPlayer.showTitle({ onContinue, continueNote, onStory, storyNote, onChallenge, challengeLabel: 'えらんで あそぶ', challengeNote })`。
