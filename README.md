# white-squid（街と、その白い壁 〜The City and Its White Squid〜）

たて画面の 台を 上から 見下ろす、**ビリヤード（モンスト）風の 物理パズル** です。
画面の どこでも 指で **ひっぱって はなす** と、下の 発射口から 反対向きに タコが とびだします。
タコは 台の ふちや ブロックで はねかえり、ゆっくり 回りながら すべって、止まると **場に のこります**。
のこった タコに あてると **コンボ**。白い 壁に まもられた **イカ** の 体力（ハート）を 0 に するか、
イカを **四すみの 穴** に おとせば 勝ちです。

前作 [cat-on-escape（猫が消えた街）](https://github.com/pikaring/cat-on-escape) の 続編です。
バックエンドなし（HTML / CSS / Vanilla JavaScript のみ）。物理演算も 自前で、依存ライブラリは ありません。
進み具合は LocalStorage に 保存します。見た目と 操作感は 前作に 合わせて あります。

**紹介ページ → https://pikaring.github.io/white-squid/**
**あそぶ → https://pikaring.github.io/white-squid/app/**

## 遊びかた

1. 下の **トレイ** で 投げる タコを、その下の ボタンで **投げる 人** を えらびます。
2. 画面の どこでも 指（または マウス）で **ひっぱる** と 予測線が 出ます。とぶ 向きは ひいた 向きの 反対、ひく 長さが 強さです。
   予測線は 台の ふちや ブロックで はねかえる 道すじを 見せます（長さは 投げる 人で ちがう）。
3. **はなす** と 下の 発射口から タコが とびだします。はねかえりながら ゆっくり 回って すべり、止まると 場に のこります。
   タコ四郎・タコ五郎は、うごいて いる あいだに タップすると わざが 出ます。
4. **場に のこった タコに あてると コンボ**。コンボの ついた タコが イカに あたると、コンボ 1つごとに ダメージが ＋50% です。
5. イカの 体力（ハート）を 0 に するか、イカを はじいて **四すみの 穴** に おとせば 勝ち。

- はじめに 使えるのは **ナオと タコ一郎だけ**。台の 上や ブロックの 中の **アイテム** に タコを あてると、
  フミ・マキ・チカが なかまに なったり、タコ二郎〜七郎・タコ大王が 1ぴき ふえたり します。
- 手に 入れた アイテムは、クリアすると **同じ 面の つぎの レベルに もちこせます**（X-1 → X-2 → X-3）。
  なかまは **のこり 回数** を、タコは **投げずに あまった ぶん** を もちこします。**面が かわると もちこしは なし**（X-1 は いつも ナオと タコ一郎だけ）。
  やりなおしても、もちこした ぶんは そのまま です。

### 得点と ハイスコア

クリアすると レベルの 得点が 出て、**面（3レベル）の 合計で ハイスコア** を ねらいます。

| 得点 | 点 |
| --- | --- |
| イカへの ダメージ | ハート 1つ 100 |
| 穴に おとした | 1,000 ＋ のこって いた ハート 1つ **500**（体力が 多い うちに おとすほど 高い） |
| さいだい コンボ（2 以上） | コンボ 1つ 200 |
| のこった タコ一郎 | 1ぴき 300 |
| 面の さいご（X-3）：あまった タコ二郎〜大王 | 1ぴき 500 |
| 面の さいご（X-3）：なかまの のこり 回数 | 1回 300 |

- 面の 合計は、その 面の 3レベルを さいごに クリアした ときの 得点の 和 ＋ あまった アイテムの 得点。
- ハイスコアは 面ごとに 保存され、「えらんで あそぶ」の 面の 見出しにも 出ます。数値は `app/main.js` の `PT`。

- 1面の はじめは 1回 あてれば 勝ち。面が すすむと イカの 体力も、タコの かずも ふえます（1面 3びき → 8面 9ひき）。
- 台は よこ長の よこ 13マス × たて 8マス（スマホの 画面を よこいっぱいに 使い、コマが 大きく 見えます）。イカは 左か 右に よって、四角い ブロックの 白い 壁に まもられて います。
- 四すみの 穴には **タコや 白い 玉も おちます**（おちた タコは もどりません）。
- チカの 小さい タコは よく すべる ので、あとから 別の タコを ぶつけると 遠くまで とんで コンボに つながります。
- なかま（フミ・マキ・チカ）は アイテム 1つで **3回** 投げて もらえます。のこり 回数は ボタンの 右上。0に なると ナオに もどります。

| ブロック | とくちょう |
| --- | --- |
| 白 `W` | 2回 あてると こわれる |
| かたい `H` | ふつうの タコでは こわれない。タコ二郎で けずれる。**爆発（マキ・タコ六郎・赤い ブロック）なら 1回で こわれる**（タコ七郎の スミで 白に なる） |
| 赤 `R` | あたると 大きく 爆発して まわりの ブロックを こわし、ちかくの イカにも ダメージ（イカの そばに 置いて ある） |
| 白い 玉 `O` | あてると うごく。玉に あてると コンボ、玉が イカに あたれば ダメージ |

- **穴に おとせば 一発 勝利**（イカの 体力が のこって いても）。★が 1つ おまけ。のこって いた 体力 1つごとに 500点の ボーナス。
  穴は 大きめで、イカの 体が 穴の ふちに かかれば 落ちます。
- ★：勝った とき のこった タコが 2ひき 以上で ★3、1ぴきで ★2、0で ★1。穴に おとしたら ★+1（最大 ★3）。
- タコが なくなっても イカが のこって いれば「もういちど」。同じ 台に すぐ いどめます。
- 保存キーは `throwontako.story`（`{ level, stars, seenPrologue, carry, scores, best }`。`carry` は つぎの レベルへ もちこす アイテム、`scores` は レベルの 得点、`best` は 面の ハイスコア）。サーバーには 何も 送りません。

### タコの わざ

面が すすむごとに、投げられる タコが 1しゅるいずつ ふえます（1面の タコ一郎 → 8面の タコ大王）。
数値は `app/game.js` の `TAKOS`。

| タコ | 仲間に なる 面 | わざ |
| --- | --- | --- |
| タコ一郎 | 1 通学路 | ふつうの タコ |
| タコ二郎 | 2 商店街 | おもくて、白い ブロックを つきぬける。かたい ブロックも こわせる |
| タコ三郎 | 3 トンネル | よく はねて、長く すべる |
| タコ四郎 | 4 イカの 壁工場 | うごいて いる あいだに タップすると **スミ レーザー**。すすむ 向きに まっすぐ、線の 上の ブロックを（かたい ものも）こわし、タコ・玉・イカを ふきとばす。跡は のこらず、四郎も 消える |
| タコ五郎 | 5 砂浜 | うごいて いる あいだに タップすると イカへ まっしぐら |
| タコ六郎 | 6 海の 上 | ぶつかって 1びょう後に 大ばくはつ |
| タコ七郎 | 7 イカの 城 | スミで まわりの ブロックを もろく する（かたい → 白）。スミの かかった イカは ダメージ 1.5ばい |
| タコ大王 | 8 女王の 間 | 大きくて おもい。はじめて ぶつかった とき、大きな ゆれで まわりを ふきとばす |

### 投げる 人の とくちょう

同じ タコでも、投げる 人で ねらいと 当たりかたが かわります。数値は `app/game.js` の `THROWERS`（力は イカへの ダメージの 倍率）。

| 人 | 使える 面 | とくちょう |
| --- | --- | --- |
| ナオ | 1〜（はじめから） | ねらい ◎（ぶれ なし・予測線が いちばん 長い・4° 以内なら イカに あたる 向きへ よせる「ねらい補正」）。力 △ 0.8 |
| フミ | 1〜 | 力 ◎ 1.6。そのかわり ねらい △（ぶれる・予測線が 短い） |
| マキ | 1〜 | ねらい・力とも 中くらい（1.1）。はじめて ぶつかった とき 小さな 爆発 |
| チカ | 2〜 | 小さい タコを 3びき いっぺんに 投げる（1ぴきの 力は 0.6） |

## ストーリー「街と、その白い壁」

タコ大王の 事件（前作）から しばらく。猫は 塀の 上で ひなたぼっこ、タコたちは 商店街の 人気者。
ところが ある朝、女子高生の **ナオ**（小柄・黒髪メガネ）と **フミ**（大柄・茶髪のギャル）の 住む 街が、
まっしろな 壁で ぐるりと かこまれて しまいます。

けっても おしても びくとも しない 壁。その 下で「朝練に 間に合わない」と ボールを ぶつけて いた
ソフトボール部の エース **マキ** が、まちがえて タコを 投げたら 壁が くずれた ―― そこへ 壁を まもる **イカ子** が 登場。
ただし こわした 壁は すぐ 元に もどって しまう。タコが 足りない 4人は、商店街の 魚屋の 娘 **チカ** と **タコ大王** の 力を かり、
壁を こわしながら 海の 向こうの **イカ女王** の 城を めざします。

- 全8面・24レベル（1面＝3つの 台）。面の はじめと 3つめの 台の あとに 会話の 場面が あります。
- 背景の 絵が 出るのは 会話の 場面だけ。ゲームの 画面は 見やすい 空色の 台です。

| 面 | 場所 | 相手 | できごと |
| --- | --- | --- | --- |
| 1 | 通学路 | イカ子 | マキが まちがえて 投げた タコで 壁が くずれ、イカ子が 登場。でも 壁は すぐ 復活して 外へ 出られない |
| 2 | 迷路の 商店街 | イカ美 | 街の 中にも 壁が ふえて 迷路に。チカが タコ大王を つれて 仲間に（大王は 腰を 悪くした チカの 父の かわりに 魚屋を 手伝って いる） |
| 3 | トンネル | イカ乃 | 街の 外へ 出ようと すると じゃま。イカ女王の たくらみが あきらかに |
| 4 | イカの 壁工場 | イカ里 | 壁を つくる 工場を 止める。海へ つづく 吸盤の あと |
| 5 | 砂浜 | イカ代 | 遠くに 女王の 城。イカ代が「女王さまを 止めて」と たのむ |
| 6 | 海の 上 | イカ江 | タコ大王の ジェット噴射で 船を 進める。手下たちは 乗り気で なく、抜け道を おしえる |
| 7 | イカの 城 | イカ奈（親衛隊長） | 女王の 間の 手前で たたかう |
| 8 | 女王の 間 | イカ女王 | 壁の ほんとうの わけ。女王も 陸に 上がり、タコ大王と いっしょに 魚屋で はたらく |

- タイトルで「はじめから」「つづきから」「えらんで あそぶ」（クリアした 台を 会話なしで）を えらべます。

台本は `app/story-data.js` を 書きかえるだけで 変えられます。
まだ ない 絵（背景〈白い壁・砂浜・海・城の 中・女王の 間〉・タイトル・ロゴ・エンディング）は
`docs/asset-prompts.md` の プロンプトで 作り、`app/images/story/` に 置くと 自動で 出ます。

## アイコン

`tools/make_icons.py` が タイトルロゴ（`app/images/story/logo.png`）と、チカ・マキの 立ち絵から、
空と 海の 色の 角丸に ロゴ（上）と ふたりの 顔（下）を のせた アイコンを つくります
（前作 cat-on-escape と おなじ 図がら）。64px 以下は ロゴが つぶれるので 顔だけです。

```
pip install pillow numpy
python3 tools/make_icons.py
python3 tools/make_icons.py app/images/story/chika-happy.png app/images/story/maki-happy.png app/images/story/logo.png
```

`app/images/icon-32/180/192/512.png` と `assets/icon.png`（512px）・`assets/favicon.png`（64px）を 書き出します。

## 紹介ページの 本・グッズ（Amazonアソシエイト）

`index.html` の `<div class="good" data-asin="...">` が商品カードです。ほかのサイト
（reach-on-sanma・cat-on-escape など）と同じ形式で、リンクは `https://www.amazon.co.jp/dp/ASIN?tag=redcomet-22`。
いまは 前作 cat-on-escape で 実在を 確かめた 4つを そのまま 置いて います。

画像と価格は `assets/goods.json` から後付けで差し込みます（無ければテキストのまま表示）。
生成は `tools/fetch_goods.py`、毎日の更新は `.github/workflows/goods.yml` が担当します。

動かすには、リポジトリの Settings → Secrets and variables → Actions に
`CREATORS_CLIENT_ID` と `CREATORS_CLIENT_SECRET` を登録してください。
登録するまでのあいだ、ワークフローは失敗せずに何もしません（画像と価格が出ないだけで、
アフィリエイトのリンク自体は Secret と関係なく動きます）。

## 公開の 手順

公開 URL は `https://pikaring.github.io/white-squid/` を 前提に 書いて あります
（`index.html` の canonical・OG・JSON-LD、`app/index.html` の canonical、`sitemap.xml`）。

1. **リポジトリ名は `white-squid`**（`pikaring-throw-on-tako` から 改名ずみ）。
   名前を 変える ときは、上の ファイルと この README の URL を ぜんぶ 書きかえる。
2. **GitHub Pages を 有効に する**
   Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `/ (root)`。
   数分後に 紹介ページと `/app/` が 開けるか 確かめる。
3. **Secrets を 登録する**（本・グッズの 画像と 価格を 出す とき）
   `CREATORS_CLIENT_ID` / `CREATORS_CLIENT_SECRET`。Actions の `goods` ワークフローを 1回 手動で 動かすと すぐ 反映される。
4. **`pikaring.github.io` リポジトリ（ポータル）の 側で**
   - 一覧（根の `index.html`）に white-squid の カードを 足す（アイコンは `https://pikaring.github.io/white-squid/assets/icon.png`）。
     ポータルの JSON-LD（`ItemList`）にも 1つ 足す
   - 根の `robots.txt` に `Sitemap: https://pikaring.github.io/white-squid/sitemap.xml` の 行を 足す
     （robots.txt は 根に 1つだけ。このリポジトリには 置かない）
5. **Search Console** で URLプレフィックスの プロパティ `https://pikaring.github.io/white-squid/` を 足し、
   `sitemap.xml` を 送信する（確認ファイルを 置いたら 消さずに 残す）。
6. GA4 は 紹介ページに 入れて あるので、設定は いらない（測定ID `G-3FCFQY4W85` を ほかの サイトと 共用。`/app/` には 入れない）。
7. 実際の 画面の 画像（`assets/og.png`）が できたら、`index.html` の JSON-LD に `screenshot` を 足す（`og:image` は `assets/icon.png` の まま）。
