どんなゲーム

はじいて、はねかえして、コンボで たおす。

たて長の 台を 上から 見下ろす、ビリヤードの ような 物理パズルです。 白い 壁に まもられた イカの 体力（ハート）を 0 に したら 勝ち。 1面の はじめは 1回 あてれば 勝てますが、面が すすむと イカの 体力も、投げられる タコの かずも ふえて いきます。

01

ひっぱって、はなす

画面の どこでも 指で ひっぱって はなすと、下の 発射口から 反対向きに タコが とびだします。ひく 長さが 強さ。 予測線は 台の ふちや ブロックで はねかえる 道すじまで 見せて くれます。

  • マウスの ドラッグでも、指でも 同じ 操作
  • 予測線の 長さは 投げる 人で ちがう
02

のこった タコで コンボ

タコは はねかえりながら ゆっくり 回って すべり、止まると 場に のこります。 つぎの タコを のこった タコに あてると コンボ。コンボの ついた タコが イカに あたると、コンボ 1つごとに ダメージが ＋50%。

  • はねかえりを つかって 壁の うらへ まわす
  • 場の タコを ビリヤードの 玉の ように 使う
03

白い 壁と、四すみの 穴

イカの まわりは 四角い ブロックの 壁。白は 2回 あてると こわれ、かたい ブロックは こわれず、赤は あたると 爆発して まわりの ブロックと ちかくの イカに ダメージ。 そして イカを はじいて 四すみの 穴に おとせば、体力が のこって いても 一発 勝利です。

  • 白い 玉 → あてると うごいて コンボに なる
  • 白 → 2回で こわれる、かたい → ふつうの タコでは こわれない（二郎と 爆発なら こわせる）、赤 → 爆発
  • 穴に おとすと ★が 1つ おまけ
04

8しゅるいの タコと 4人の 投げる 人

面が すすむと、投げられる タコが ふえます。白い ブロックを つきぬける タコ、タップで わかれる タコ、イカへ まっしぐらの タコ……。 ねらいの ナオ、力の フミ、爆発の マキ、3びき いっぺんの チカ。同じ タコでも、投げる 人で まるで ちがう 動きに なります。

  • 下の トレイで タコを えらぶ（のこりの かず つき）
  • 投げる たびに 人を かえられる（チカは 2面から）
05

★と やりなおし

タコを のこして 勝つほど ★が ふえます（のこり 2ひき 以上で ★3、1ぴきで ★2、0で ★1）。穴に おとして 勝てば ★が 1つ おまけ。 タコが なくなっても イカが のこって いたら、同じ 台に すぐ「もういちど」。

  • 進んだ レベルと ★は この端末の中だけに 保存
  • 「えらんで あそぶ」で クリアした 台に もう一度
06

おおきな文字・おおきなボタン

前作 猫が消えた街 と 同じ 見やすさの つくり。高コントラストで、押すところは すべて 48px 以上。ひらがな中心の わかち書きです。

  • 物理演算も 自前。依存ライブラリなし
  • 動きを へらす 設定（prefers-reduced-motion）に 対応

はじかれて くれる、8ひきの タコ。

投げる人

だれが 投げるかで、タコの 動きが かわる。

前作の ナオと フミに、ソフトボール部の エース マキと、商店街の 魚屋の 娘 チカが くわわります。

ナ

ねらい ◎ ／ 力 △

ナオ

ねらいが 正確で、ぶれが ない。予測線が いちばん 長く、はねかえりの 先まで 見える。イカを すこし 外しても 「ねらい補正」で あたる 向きに よせて くれる。そのかわり 力は 0.8 と 弱め。

フ

ねらい △ ／ 力 ◎

フミ

マキ

となりの クラスの ソフト部 エース。ねらいも 力（1.1）も 中くらいで、はじめて ぶつかった とき 小さな 爆発が おきる。

チ

ちいさく 3びき

チカ

商店街の 魚屋の 娘。手が はやく、小さい タコを 3びき いっぺんに 投げる（1ぴきの 力は 0.6）。2面から。

あそびかた

ひっぱって、はなすだけ。

1下の トレイで タコを、その下の ボタンで 投げる 人を えらぶ
2画面の どこでも ひっぱる。とぶ 向きは ひいた 向きの 反対、ひく 長さが 強さ。はねかえる 予測線で ねらう。点線の 下を タップすると 発射口が 左右に うごく
3はなすと 下の 発射口から タコが とびだす。ふちや ブロックで はねかえり、止まると 場に のこる。タコに よっては うごいて いる あいだに タップで わざ
4のこった タコに あてると コンボ。コンボの ついた タコで イカを 攻撃すると ダメージ アップ
5イカの ハートを 0 に するか、イカを 四すみの 穴に おとせば 勝ち

パソコンでは マウスの ドラッグ、スマホ・タブレットでは 指で ひっぱって あそべます。

ストーリー

ある朝、街が 白い 壁で かこまれた。

タコ大王の 事件から しばらく。猫は 塀の 上で ひなたぼっこ、タコたちは 商店街の 人気者。 ところが ある朝、ナオと フミの 住む 街が まっしろな 壁で ぐるりと かこまれて しまいます。 けっても おしても びくとも しない 壁 ―― その 下で「朝練に 間に合わない」と ボールを ぶつけて いた ソフト部の エース マキ が、 まちがえて タコを 投げたら、壁が くずれた！ そこへ 壁を まもる イカ子 が あらわれます。 魚屋の 娘 チカ と タコ大王 も 仲間に くわわり、4人は 壁を こわしながら、海の 向こうの イカ女王 の 城を めざします。

01–04

とじこめられた 街から、外へ

  • 1面 通学路 ―― マキが まちがえて 投げた タコで 壁が くずれ、イカ子が 登場（イカ子）
  • 2面 迷路の 商店街 ―― チカと タコ大王が 仲間に（イカ美）
  • 3面 トンネル ―― イカ女王の たくらみが あきらかに（イカ乃）
  • 4面 イカの 壁工場 ―― 海へ つづく 吸盤の あと（イカ里）
05–08

海の 向こうの、イカの 城へ

  • 5面 砂浜 ―― 遠くに 女王の 城。イカ代の たのみ（イカ代）
  • 6面 海の 上 ―― タコ大王の ジェットで 船を 進める（イカ江）
  • 7面 イカの 城 ―― 女王の 間の 前で まちかまえる（親衛隊長 イカ奈）
  • 8面 女王の 間 ―― イカ女王が 壁を つくった ほんとうの わけ（イカ女王）

1面は 3つの 台（3レベル）。面の 前と あとに 会話の 場面が あります（タップで すすむ、右上で スキップ）。 背景の 絵は 会話の 場面で 出ます。ゲームの 画面は 見やすい 空色の 台です。 クリアした 台は タイトルの「えらんで あそぶ」から 会話なしで 遊べます。

つくり

物理演算まで、HTML / CSS / JavaScript だけ。

フレームワークも ビルドも、物理エンジンの ライブラリも 使っていません。 タコの はねかえり・すべり・回転、タコどうしの ぶつかりと コンボ、爆発や 穴への 落下は app/game.js に 自前で 書いて あります。

台の 図面は 文字の 絵app/stages.js に よこ 9マス × たて 13マスまで、Q（イカ）・W（白）・H（かたい）・R（赤）で 書くだけ。置いた ままで 動かないか、いちばん よい 投げを つづければ 入れた タコ 以内に 勝てるかは、24レベル すべて スクリプトで 確かめて います。
絵が なくても 遊べるタコや イカの 絵は 読みこめた ときだけ 使います。無ければ 図形と 名前の 札で 代わりに 出ます。
保存進んだ レベルと ★は LocalStorage に。サーバーには 何も 送りません。
動きが 苦手な 方へprefers-reduced-motion に 対応。画面の ゆれや 破片を へらします。

よくある質問

気になるところ

お金は かかりますか？

かかりません。無料で、広告も 課金も ありません。

インストールは 必要ですか？

不要です。ブラウザで開くだけ。ホーム画面に追加すると、アプリのように 全画面で 開けます。

データは どこかに 送られますか？

送られません。進んだ レベルも ★も、お使いの端末の中だけに 保存されます。

どうやって 投げますか？

画面の どこでも 指（または マウス）で ひっぱって、はなします。タコは 下の 発射口から、ひいた 向きの 反対へ とびだします。ひく 長さで 強さが 決まり、ひっぱって いる あいだは はねかえる 道すじまで 予測線が 出ます。

なかなか 勝てません

まっすぐ ぶつけるより、コンボと 穴を ねらうのが こつです。止まって 場に のこった タコに あててから イカに とどくと、コンボ 1つごとに ダメージが ＋50%。 イカが 穴の そばに いたら、はじいて 四すみの 穴に おとせば 一発 勝利です。赤い ブロックの 爆発も ちかくの イカに ききます。予測線が 長い ナオで、ふちの はねかえりを つかうと ねらいやすく なります。

タップする タコが うまく 使えません

タコ四郎（3びきに わかれる）と タコ五郎（イカへ まっしぐら）は、うごいて いる あいだに 画面の どこかを タップすると わざが 出ます。タコ五郎は、イカとの あいだに ブロックが ない ところで タップすると、まっすぐ とどきます。

前作を 遊んで いなくても 大丈夫？

大丈夫です。お話は つながって いますが、はじめの 場面で 街の ようすが わかります。前作 猫が消えた街 は、ねこを そろえて 逃がす パズルです。

ついつい やめられません

1つの 台は 数投で 終わります。クリアしたら ひと区切り。進んだ レベルは 保存されるので、つぎは「つづきから」遊べます。
